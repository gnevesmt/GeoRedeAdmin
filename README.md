# GeoRede Admin

Painel web de administração de licenças e acessos do GeoRede Book.

Este repositório contém somente a interface web pública do painel.
Autenticação, regras de licenciamento e operações administrativas sensíveis
são processadas pelo backend Supabase.

Não armazene neste repositório chaves secretas, service role keys ou senhas.
